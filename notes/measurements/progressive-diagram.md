## 重建方法与边界

- 场景：`app/scenes/progressive-diagram.js`，导出 `ProgressiveDiagramScene`，804 × 720，6.9 s。
- `stateAt(elapsed, reducedMotion)` 将时间限制在合法范围。几何、显隐、连线进度和章节切换均由时间计算，倒放与任意拖动不会依赖之前播放过的帧。
- 使用六个章节节点：0.8 / 2.2 / 3.3 / 4.6 / 6.0 / 6.6 s。节点来自采样帧观察，精度受 100 ms 帧间隔限制；卡片间的补间、滚动过渡和字体渲染由重建代码确定。
- 原片中该次回答的 SVG/HTML 未提供，无法恢复历史 token 输出或 DOM 修改时刻。本场景复现它的视觉与逐段生成叙事，不会调用模型、不执行真实训练，也没有复制 CodePilot 的 React 应用。
- 减少动态效果时取消章节入场位移，保留时间轴决定的内容状态。
- 70% / 20% / 10% 是原演示的示例训练阶段比例，画面中也标为示例，不能当成通用训练成本统计。
